# SlideReport

ساخت خودکار گزارش پاورپوینت از پوشه‌های تصویری — فارسی، RTL، شبکه ۲×۲.

## ویژگی‌ها

- تشخیص خودکار ساختار پوشه (تخت، گروه‌بندی موضوعی، زیرپوشه‌های شماره‌دار)
- شبکه ۲×۲ با حفظ نسبت تصویر
- بزرگنمایی کلیک/هاور در Slideshow
- سه تم: تیره فیروزه‌ای، تیره ارغوانی، روشن
- خروجی در `Output_PPTX` داخل همان پوشهٔ ورودی

## نصب و اجرا

```bash
pip install -r requirements.txt
python main.py
```

## میانبرها

| کلید | عمل |
|------|-----|
| `Ctrl+O` | انتخاب پوشه |
| `F5` | شروع ساخت |
| `Esc` | توقف |
| `Ctrl+Q` | خروج |
| `Ctrl+C` (ترمینال) | خروج امن |

## تست

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

## ساخت EXE پرتابل

```bash
build.bat
```

خروجی: `dist\SlideReport_Portable.exe`

Build از **UPX** (در صورت در دسترس بودن) برای فشرده‌سازی استفاده می‌کند؛ در غیر این صورت بدون UPX ساخته می‌شود.
