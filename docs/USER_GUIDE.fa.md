# راهنمای کاربر

[English](USER_GUIDE.md) · [بازگشت به README](../README.fa.md)

راهنمای کامل **Pics2PPT** برای کاربران.

---

## ۱. روش نصب

### EXE پرتابل (پیشنهادی)

1. `Pics2PPT.exe` را از Releases یا `dist\` بگیرید.
2. هر جا قرار دهید (Desktop، USB).
3. نصب و Python لازم نیست.
4. SmartScreen: **Run anyway**

### از سورس

```bash
pip install -r requirements.txt
python main.py
```

## ۳. گام‌به‌گام

### گام ۱ — آماده‌سازی پوشه

قوانین:
- فقط `.jpg` / `.png` در پوشه‌های برگ
- `.rar` اسکن نمی‌شود
- عکس فقط در Output نگذارید

### گام ۲ — انتخاب مسیر

| هدف | چه مسیری انتخاب شود |
|-----|---------------------|
| یک موضوع تخت | همان پوشهٔ عکس‌ها |
| یک شخص + موضوعات | پوشهٔ شخص |
| کل پروژه | **ریشه پروژه** |

### گام ۳ — پاورقی و لوگو (اختیاری)

- **پاورقی** — پایین هر اسلide
- **لوگو چپ/راست** — سربرگ

### گام ۴ — شروع

**شروع ساخت** یا `F5`. **توقف** یا `Esc`.

**پروژه چند job:** دیالوگ محل ذخیره:

| انتخاب | نتیجه |
|--------|--------|
| **داخل هر پوشه** | `<واحد>\Output_PPTX\<واحد>.pptx` |
| **یکجا** | `<ریشه>\Output_PPTX\*.pptx` |

**تداخل PPTX:** جایگزین · نسخه جدید `(۲)` · انصراف.

**پاک کردن ورودی‌ها** — ریست مسیر، پاورقی، لوگو.

> ورودی‌های جلسه (مسیر، پاورقی، لوگو) **بین اجراها ذخیره نمی‌شوند**.

### گام ۵ — خروجی

پس از موفقیت از دیالوگ استفاده کنید: باز کردن پوشه خروجی، ورودی، یا PPTX.

```text
داخل هر پوشه:  <واحد>\Output_PPTX\<واحد>.pptx
یکجا:         <ریشه>\Output_PPTX\<job>.pptx
```

## ۴. تنظیمات

### ظاهر و زبان

| تنظیم | مقادیر | اثر |
|-------|--------|-----|
| تم | dark_cyan، dark_purple، light | رنگ رابط |
| اندازه فونت | کوچک / متوسط / بزرگ | مقیاس متن UI |
| **زبان رابط** | فارسی · English | کل رابط و راهنما (تعویض زنده) |
| **محتوای اسلاید** | همان زبان رابط · فارسی · انگلیسی | عناوین بخش و RTL/LTR/فونت داخل PPTX |

> **تفاوت زبان رابط و اسلاید:** زبان رابط منوها و لاگ را کنترل می‌کند. زبان اسلاید آنچه *داخل فایل `.pptx`* ظاهر می‌شود را کنترل می‌کند. پیش‌فرض **همان زبان رابط** است.
>
> در **نصب کاملاً تازه**، هنگام اولین اجرا دیالوگ دوزبانه (**فارسی** / **English**) باز می‌شود. گزینهٔ پیشنهادی از locale ویندوز می‌آید؛ بعداً هم از تنظیمات قابل تغییر است.

### کیفیت و ویژگی‌ها

| تنظیم | پیشنهاد |
|-------|---------|
| کیفیت JPEG 75 | تعادل حجم/کیفیت |
| ابعاد 1200 | مناسب پروژکتور |
| جداکننده بخش | برای چند موضوع |
| زوم کلیک/هاور | برای جلسات |

## ۵. ارائه

1. `.pptx` را در PowerPoint دسکتاپ باز کنید.
2. Slideshow (`F5`)
3. **کلیک** روی تصویر → اسلاید جزئیات
4. **هاور** → همان (در PowerPoint دسکتاپ)
